04 · STRATEGY MAP
히트맵 탭 연말까지 무료
📌 히트맵이란?
내가 달린 모든 배달이 지도 위에 쌓입니다.
데이터가 쌓일수록 "어디로 이동해야 콜을 더 받을 수 있는지" 지도가 알려줍니다.
🔢 데이터 단계별 기능
건수활성화 기능
0~99건지도만 표시 (마커 없음)
100건+마커 표시 시작
300건+Hot Zone(빨강) · Ice Zone(파랑) 표시
500건+시간대별 패턴 분석
🎯 Hot Zone · Ice Zone
🔴 Hot Zone — 콜이 집중되는 구간. 지금 당장 이동해야 할 곳
🔵 Ice Zone — 콜이 드문 구간. 피해야 할 곳
🗓️ 필터 사용법
요일 필터 (상단) — 월~일 버튼으로 특정 요일만 보기
시간대 필터 (하단) — 오전 · 점피 · 오후 · 저피 · 야간 · 심야
💡 활용 예시: 금요일 + 저피 선택 → "금요일 저녁 피크에 어디로 가야 하나?" 확인
⚠️ 주의: 도착→픽업→드롭 버튼을 눌러야 히트맵 데이터가 쌓입니다. 정산만 입력하면 히트맵에는 반영되지 않아요.

10 · FAQ
자주 묻는 질문
히트맵이 비어있어요
도착→픽업→드롭 버튼을 눌러야 데이터가 쌓입니다. 100건부터 마커가 표시돼요. 정산만 입력하면 히트맵에는 반영되지 않아요.
날씨가 안 나와요
GPS가 수신되면 자동으로 표시됩니다. 실내에서는 느릴 수 있어요. 위치 권한이 허용됐는지 확인해주세요.
폰 바꿨는데 데이터가 없어요
기존 폰에서 백업 파일 내보내기 → 새 폰에서 복원하면 됩니다. 백업 없이 폰을 바꾸면 복구가 불가능해요.
PIN을 잊었어요
PIN 분실 시 복구 방법이 없습니다. 앱 삭제 후 재설치해야 하며 데이터는 복구되지 않아요. 백업 파일이 있다면 재설치 후 복원 가능합니다.
비밀번호 음성 안내가 안 돼요
장소 저장 시 GPS 좌표가 필요합니다. 현장에서 "현위치 저장" 버튼을 눌러 좌표를 등록해야 근접 안내가 작동해요.
데이터가 어디에 저장되나요?
모든 데이터는 내 폰 안에만 저장됩니다. 서버가 없어요. 개발자도 데이터를 볼 수 없습니다.
연말 유료 전환 시 데이터는?
데이터는 그대로 유지됩니다. 유료 전환은 블러 기능 활성화만 변경되며 기존 데이터에는 전혀 영향이 없어요.
